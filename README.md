# Plast Up frontend (mandiri)

Tanpa backend — auth/TPS/legal demo di `src/lib/demo-auth.ts`, `src/config/*`.

```bash
npm install
npm run dev
```

Buka http://localhost:3001

| Route | Keterangan |
|-------|------------|
| `/login` | Masuk pengguna (demo) |
| `/register` | Daftar + 23 TPS + legal |
| `/admin/login` | Masuk staff |
| `/portal` | Setelah login pengguna |

Assets: `public/brand/`, `public/mascot/`, `public/icons/`.
